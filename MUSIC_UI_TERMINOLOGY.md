# Music UI Terminology

Use these names when discussing Music app controls.

## Window Traffic Lights

The native red, yellow, and green macOS window controls.

- Must stay native.
- Must keep their accepted position.
- Must remain concentric with the sidebar and outer window corners.
- Do not restyle these as custom app buttons.

## Icon-Only Controls

Symbol-only buttons with no visible button body, but with an invisible circular
hit target around the symbol.

Examples:

- Play Bar shuffle, previous, play/pause, next, repeat.
- Play Bar more, queue, and volume buttons.
- Small row-only utility icons when they are intentionally icon-only.

## Sidebar Navigation Rows

The left sidebar rows Leo originally called menu bar buttons.

- White when not selected.
- Red when selected.
- Whole row must be clickable.
- Selected row gets a subtle gray rounded background.

## Capsule Action Buttons

Visible action buttons used outside the Play Bar and sidebar.

Examples:

- Play
- Refresh
- Next
- Back
- Confirm
- Create
- Use

Rules:

- Semicircle/capsule ends.
- Neutral buttons stay black-ish.
- Primary buttons use the app accent color.
- Subtle Liquid Glass lighting is allowed when it improves polish.

## Context Menu Items

Native right-click or `...` menu entries.

- Keep them native menu rows.
- Do not restyle them as capsule buttons.
