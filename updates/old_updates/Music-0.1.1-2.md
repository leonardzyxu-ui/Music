# Music 0.1.1

This update prepares Music for signed Sparkle update testing.

## What's New

- Added the first signed Sparkle update feed used by Music.
- Added a manual update path in Settings and the app menu.
- Added release validation for Sparkle framework embedding, appcast URL, public
  update key configuration, and automatic update checks.
- Improved the website download panel with visible version information.

## Notes

- Music keeps playback and library data local to the user's Mac.
- YouTube import depends on helper tools being available on the Mac.
