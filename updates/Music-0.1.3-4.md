# Music 0.1.3

This update improves Sparkle update stability and keeps the first rollout build
on the safer update path.

## What's New

- Stabilized the Sparkle update flow when checking from Settings.
- Kept custom Music window sizing and chrome behavior scoped to the main player
  window, so auxiliary windows stay under normal macOS control.
- Refreshed the public appcast with embedded release notes and signed update
  metadata.

## Notes

- YouTube import still depends on helper tools being available on the Mac.
- Music keeps playback and library data local to the user's Mac.
